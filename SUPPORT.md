# SUPPORT.md for driftcheck

## Getting Help

- **Bug Reports:** Open an issue with the `bug` label. Include your OS, Python version, and the detector that failed.
- **Feature Requests:** Open an issue with the `enhancement` label describing the tool/dependency you want drift detection for.
- **Usage Questions:** Open an issue with the `question` label.

## Community
- GitHub Discussions: Not yet available — use Issues for now.
- Discord/IRC: Not available.

| Channel | Response Time |
|---------|--------------|
